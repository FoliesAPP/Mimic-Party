# ✨ Pokémon Nova – Full Release Announcement! ✨

Welcome to **Pokémon Nova**, a fan game set in the mysterious **Ultra Megalopolis** from **Pokémon Ultra Sun & Ultra Moon**!

## 🌌 Features

* 🗺️ **Open-world adventure** with **25+ hours** of story content
* 🏆 Challenge **20 Rank Leaders** on your journey
* ⭐ **Postgame content included**
* 🌍 Available in **English 🇬🇧** and **Spanish 🇪🇸**
